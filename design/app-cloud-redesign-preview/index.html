IMPLEMENTATION NOTES

实施时必须守住的四条规则

01

旧数据先迁移后清理

使用原有 UUID 做幂等去重，记录与照片全部核对成功后，再删除本地 Room 数据与旧照片。

02

服务端判断数据归属

创建者必须由登录 Token 决定，APP 不允许自行传入或修改 creator_id，避免越权。

03

表单从第一步就是云端草稿

用户信息完成后建立 draft，字段防抖保存，照片独立上传；提交只是把草稿状态改为正式记录。

04

强在线必须有明确失败状态

断网时不假装已保存。页面明确标注“尚未保存”，恢复连接后继续，最终提交前必须通过完整性检查。
