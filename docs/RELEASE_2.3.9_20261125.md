# 2.3.9 已整改记录补录照片

Android 版本：2.3.9（34）。手机 H5 / 后端版本：20261125-photo-supplement。

## 使用方法

1. 打开「我的记录」，进入一条已整改记录的详情。
2. Android 点击「补录整改照片」；手机 H5 在详情底部使用同名表单。
3. 默认追加一张照片；要替换错图，Android 选择对应原照片，H5 在「补录方式」中选择对应照片。
4. 从相册选择照片，填写补录原因后保存。可分次补录多张，单张支持 JPG、PNG、WebP，最大 10 MB。

同公司账号可以协助补录，权限沿用现有公司整改范围。总部账号沿用既有跨公司权限；其他公司账号不能修改。仅已整改记录可补录，待整改记录仍走原整改流程。

## 数据和兼容

- 每次操作记录实际操作人、时间、原因和新图；替换的原图信息写入 audit_logs，原图片文件保留。详情和新导出读取当前照片，已生成的旧导出文件保持当时内容。
- 不修改原检查归属、整改日期、整改人、整改情况或闭环状态。按操作编号防止网络重试产生重复照片，替换冲突时要求刷新。
- 复用现有 audit_logs 和 record_photos，无数据库迁移。发布前核对现有日志表。
- 新增 POST /api/records/{id}/rectification-photo；详情的 canSupplementRectificationPhoto 声明补录能力。旧 APP 继续使用现有接口；新版 APP/H5 连接旧后端时不显示补录入口。
- 正式安装包沿用原签名，覆盖升级不卸载原应用；登录是否继续有效按服务器会话规则判断。
