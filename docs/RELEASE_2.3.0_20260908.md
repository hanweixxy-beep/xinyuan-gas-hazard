# 2.3.0 发布说明

## 业务变化

- 片区、门店是检查对象的归属信息。管理员维护公司下的片区、门店，门店必须属于一个片区。
- 新建账号和修改账号权限不再分配片区、门店。账号的公司、角色、登录端和数据查看权限继续独立管理。
- APP 和 H5 首次检查必须选择片区、门店；后续检查沿用该账号上次确认的选择，可随时更换。
- 更换片区后，需重新选择该片区下的门店。停用或不属于当前公司的选项不能用于新检查。
- 新的正式检查必须包含片区和门店。草稿可以暂时缺少这两项，正式提交前必须补全。
- 管理后台筛选及 Excel 导出继续使用每条检查记录保存的片区、门店。

## 兼容与升级

- Android 版本名称 `2.3.0`，versionCode `25`，使用既有正式签名，可覆盖安装。
- APK 位置：`outputs/releases/xinyuan-gas-hazard-v2.3.0.apk`。
- APK SHA-256：`9252D9A8E0CCAB45232834101518CF9A74446FF4E25580C615AEF1ECFF7EB6C1`。
- 不需要数据库结构迁移。历史检查记录及照片不变。
- 旧版 APP 的历史同步接口 `/api/records` 继续允许导入没有片区、门店的数据，不使用账号归属补写历史记录。
- 新 APP/H5 使用 `/api/records/drafts/submit`，服务器在此处强制校验两项必选及公司、片区、门店之间的关系。
- 旧用户表中的片区、门店字段保留兼容，但新版账号管理和检查选择不再依赖这些字段。
- 本机仅记住该账号上次选择的片区、门店作为表单偏好，不因此保存新的检查记录。

## 启用顺序

1. 在电脑后台“组织与账号”中录入实际片区、门店名称。
2. 给人员创建公司账号并设置使用权限，无需绑定门店。
3. 覆盖安装新版 APP，或刷新手机 H5 页面。
4. 检查时在“本次检查归属”中选择片区、门店，确认后继续登记。
