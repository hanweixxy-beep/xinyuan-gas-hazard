# 后台照片导出优化

2026-10-20：经用户同意，已完成独立测试、备份及正式发布。

## 使用方式

1. 在电脑后台“检查记录”中设置筛选条件，点击“导出 Excel”；或在“数据导出”中点击“新建带图导出”。
2. 系统固定提交时有权查看的记录范围，后台读取记录最新内容并生成带图 Excel，可离开或关闭页面。
3. 返回“数据导出”查看进度，完成后下载全部分包。文件保留 7 天，可取消排队或正在生成的任务。

## 本次行为

- 导出照片使用 JPEG 压缩副本，最长边不超过 1600 像素，保留 EXIF 方向；不修改上传原图。
- 默认按 1000 条记录、300 张照片、约 40 MiB 压缩图体积触发分包。单条记录保持完整，单条自身超出预算时会单独成包，因此上述值不是文件大小的硬上限。
- 以 50 条为一批读取记录及子项，避免逐条查询照片和隐患；工作簿按分包生成，保持原有列顺序、多照片展开、文本手机号和跨包连续序号。
- 后台任务没有原来的 5000 条截断限制。旧同步接口遇到超过 5000 条时明确返回提示，防止生成不完整文件。
- 每个账号同时仅允许一个进行中的任务。缺失、损坏、不支持或超过 2400 万像素的照片会计数提示，表内显示提示，并提供异常清单。
- 下载前重新验证账号状态、权限和登录会话，使用 120 秒有效的分包下载凭证；浏览器直接下载文件，避免先把整个文件缓存在页面内存。
- 原图细节应在系统中查看；导出副本用于日常查看、报送和打印。

## 后台与存储

- 复用现有 `export_jobs` 表，没有数据库结构变更。
- 服务：`xinyuan-export-worker.service`，以 www-data 运行，已启用开机启动。独占锁避免多个消费者同时处理；重启后把未完成任务标记失败并提示重新提交。
- 私有导出目录：`/var/lib/xinyuan-gas-exports`，位于网站公开目录之外，权限 0700；没有修改 Nginx 配置或其他 H5 项目。
- 已完成、失败或取消任务保留 7 天；闲置图片缓存保留 30 天，后台每小时清理。下载文件完成后 7 天过期，即使清理尚未执行也拒绝下载。
- 账号权限变化或快照中的记录被删除、不可访问时明确失败，避免静默遗漏。临时断网不影响后台处理。
- 导出文件过期后可重新提交。生成失败可查看服务日志；技术错误不向浏览器暴露内部路径或数据库连接信息。
