# 后台片区与门店编辑

## 使用方式

在后台“组织与账号”的片区列表、门店列表中，点击“操作”下的“编辑”。
弹窗会带出原有内容，点击“保存修改”生效，点击“取消”或按 Esc 不保存。

- 片区：修改名称；所属公司保持不变。
- 门店：修改名称、地址。尚无检查记录或草稿的门店，可调整到同公司其他已启用片区。
- 已有检查记录或草稿的门店不能更换所属片区，以保留历史统计归属。
- 总部管理员可编辑所有公司，公司管理员只能编辑本公司，检查员不能编辑。
- 同公司片区不能重名，同片区门店不能重名。空名称、超长内容或无权限的修改会显示错误原因并保留输入。
- 原有启用、停用操作不变，编辑名称不会自动改变启停状态。

## 数据兼容

名称和地址原地修改，不删除重建片区或门店，不改写检查记录及照片。
记录、筛选、手机选项及 Excel 导出按原 ID 关联最新名称。
门店调整所属片区时与检查写入互斥校验，旧页面不能保存已经失效的片区门店组合。
不需要数据库迁移，不需要更新 Android 安装包；手机新增检查或打开选择器时会刷新选项。
