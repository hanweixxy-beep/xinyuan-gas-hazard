## 本次更新

1. APP 与手机 H5 的新增检查页增加“本次检查归属”。
2. 默认自动使用登录账号所属片区和门店，日常检查无需重复选择。
3. 临时跨区域检查时可点击“变更”，按片区联动选择门店；该选择只影响当前记录，不修改账号默认归属。
4. 记录草稿、正式提交和详情均保留本次选择的片区、门店快照。
5. 服务器校验所选片区和门店必须处于启用状态、属于当前公司，并确保门店属于所选片区。
6. 兼容尚未分配片区门店的现有账号和旧客户端：继续按公司级归属保存，不阻断现场登记。

## 使用提示

- 实际片区和门店需先在电脑管理后台建立，再给账号设置日常默认归属。
- 新增检查页显示“已自动使用账号默认归属”时无需操作。
- 只有到其他片区或门店检查时才点击“变更”。
- 下一次新增检查会重新使用账号默认归属，避免跨区选择被误带到后续记录。
