# 后台记录分页与全量统计修复

2026-10-25（用户时区）：已备份上线。

## 原因与改动

旧列表默认最多返回 1000 条，后台将已返回数组长度用作总数和统计，并在该数组上翻页。修复后后台携带 page/pageSize，服务器按现有权限和完整筛选条件分页，每页 50 条；总数、待整改数、完成数、最近七个有记录日期的趋势和待整改预览单独按全量匹配数据查询。多项隐患与气源筛选继续共用原有参数化条件。

计数和当前页在同一数据库事务快照内读取；页码超出当前范围时返回末页。筛选重新查询回到第一页，翻页保留最近成功查询的条件，查询失败保留原页，旧慢请求不能覆盖新查询结果。浏览器资源版本已更新。旧版手机接口与导出协议保持兼容。
