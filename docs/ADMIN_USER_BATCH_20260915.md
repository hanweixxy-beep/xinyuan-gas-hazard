# 后台用户导出与批量创建

## 使用入口

电脑后台 -> 公司与账号 -> 用户列表。

- **导出用户**：下载当前账号有权查看的用户信息，包含公司编码、公司名称、姓名、手机号、角色、登录端、数据范围、状态和登录时间等。不导出密码或密码摘要。
- **下载模板**：下载固定 Excel 模板，包含“批量创建用户”“填写说明”“公司编码”三个工作表。
- **批量创建**：选择填写后的模板，校验预览，全部通过后点击“确认创建”。每批最多 200 人，文件最大 2 MB。

## 模板字段

| 列 | 字段 | 规则 |
| --- | --- | --- |
| A | 公司编码 | 必填，从“公司编码”工作表复制编码，不是公司名称 |
| B | 姓名 | 必填，最多 80 个字符 |
| C | 手机号 | 必填，6-20 位数字，建议保持文本格式，不可重复 |
| D | 角色 | 检查员、公司管理员、总部管理员；空白默认检查员 |
| E | 允许登录端 | APP+后台、仅APP、仅后台；空白默认 APP+后台；管理角色不能仅APP |
| F | 查看本公司全部记录 | 是或否；空白默认否；仅对检查员生效 |
| G | 初始密码 | 必填，至少 8 个字符，最多 72 字节，不能全为空格 |

只填写“批量创建用户”的第 2-201 行，不改列名或顺序，不使用公式或合并单元格。带前导零的手机号、较长数字和密码应保持文本格式，以免 Excel 转换数字造成失真。

模板含初始密码，应限制接触人员并妥善保管。请为不同账号设置不同初始密码，交付给本人后及时修改。用户导出的信息表不含密码，不是直接导入模板。

## 权限及数据安全

- 总部管理员可管理全部公司；公司管理员只能导出本公司用户并为本公司批量创建检查员；检查员不能使用用户管理接口。
- 账号不要求绑定片区或门店，检查地点仍由登记人员按现有业务流程选择。
- 校验预览不创建账号；重复手机号（含停用账号）、无权限公司、角色越权、空缺字段等均提示错误。
- 提交时再次校验，全部账号在同一个数据库事务中创建。任一行失败全部回滚，不覆盖、更新或重置已有账号。
- 若提交中网络中断，先刷新用户列表核对结果，再重新校验。不要把网络错误当作“肯定没有创建”。
- Excel 在本机浏览器中解析，不发送到第三方；仅将规范化字段通过系统 HTTPS 接口提交。密码不写入预览、导出或浏览器持久存储。
- 无数据库结构变更，不修改检查记录、照片、APP、H5 登记页面或服务器其他项目。
