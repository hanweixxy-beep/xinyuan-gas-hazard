## 本次更新

1. APP 与手机 H5 的新增检查改为单页连续表单，不再要求按三个步骤切换。
2. 用户可自由选择信息填写顺序；拍摄任一照片前，系统会校验完整水印所需信息。
3. 门头照片获取一次新定位，隐患照片、钢瓶照片统一复用该地址和坐标。
4. APP 全部现场照片水印统一包含日期时间、用户及电话、用户地址、检查人、配送员和定位坐标。
5. 组织架构增加片区和门店，门店必须隶属于片区。
6. 新建非总部账号必须分配到片区或门店；旧账号继续兼容，可由管理员后续补充分配。
7. 新检查记录由服务器保存账号当时的片区、门店快照，人员调动不会改写历史记录。
8. 电脑后台增加片区、门店的新增、停启用、账号分配和记录筛选功能。

## 数据库

- 增量迁移：`database/patches/20260902_organization_regions_stores.sql`
- 新增表：`regions`、`stores`
- 新增账号字段：`users.region_id`、`users.store_id`
- 新增记录快照字段：`inspection_records.region_id`、`inspection_records.store_id`
- 迁移不回填历史记录，避免将旧数据错误归入某个片区或门店。
- 原有固定 Excel 导出字段和旧版 APP 数据迁移逻辑保持不变。
