# 淮北鑫远燃气隐患排查登记 APP 使用说明

版本：1.2.2（versionCode 5）

## 本版本重点

- 优化照片存储，拍照后自动压缩，降低长期使用占用的手机空间。
- Excel 导出支持带照片，CSV 导出用于快速生成轻量清单。
- 增加终端用户隐患核查清单、隐患整改、筛选导出等功能。
- 增加数据管理与备份，可生成备份包、恢复合并数据、压缩照片、清理无效照片。
- 本机备份包会在 APP 专用备份目录中以列表展示，显示备份日期、路径、大小和最新标记。
- 终端核查未清零隐患项目支持每个项目拍摄多张带水印照片。
- 数据导出生成的 Excel/CSV 改为临时文件，分享或取消后返回 APP 会自动删除，下次导出时重新生成。
- 预留云同步字段和接口，后期配置服务器时可继续对接。

## 日常使用流程

1. 首次安装后打开 APP，允许相机和定位权限。
2. 在首页选择“瓶装液化石油气隐患排查登记”或“终端隐患核查清单登记”。
3. 新建记录时填写用户、电话、地址、检查人等信息。
4. 拍摄现场照片后，照片会添加日期、时间、地址、检查人、用户、电话、定位等水印。
5. 如有隐患未清零，按对应隐患项目拍照留证；后期整改时进入“隐患整改”上传整改照片并填写整改说明。
6. 需要汇总时进入“数据导出”，按状态、日期、用户、电话、检查人、配送员等条件筛选后导出。

## 数据备份与恢复

- 本版本数据仍保存在手机本地，未配置云端服务器时不会自动上传。
- 建议定期进入“数据管理与备份”生成备份包，并分享到电脑或其他安全位置。
- 手机空间不足时，先生成备份包并确认已保存到手机外部，再清空本机业务数据继续使用。
- 更换手机或手机空间充足后，可从备份包恢复；恢复会按记录唯一编号合并，支持多次导入，尽量避免重复记录。
- 升级 APK 一般不会影响已有数据，但升级前仍建议先生成备份包。

## 签名与升级注意事项

- 正式 APK 使用固定 release 签名生成。
- 后续升级必须使用同一个签名文件，否则 Android 会认为是另一个应用，无法覆盖安装。
- 签名文件和密码只保存在本机 `D:\GasHazardApp\signing`，不会提交到 GitHub，请务必备份。
