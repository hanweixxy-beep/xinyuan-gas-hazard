## 本次修复

1. APP 不再读取可能长期不变的系统缓存位置；门头拍照时主动请求 GPS/网络新位置。
2. 超过 30 秒或精度差于 100 米的位置不会被采用，30 米以内可提前完成定位。
3. 定位时间、定位精度和经纬度随记录及照片上传，便于后台核查定位质量。
4. 同一条记录仅在门头拍照时获取一次位置，后续照片复用该位置和地址。
5. 总部管理员、公司管理员默认可同时登录 APP 和电脑后台。
6. 检查员默认只查看本人记录；管理员可按账号授予查看本公司全部记录的只读权限。
7. 被授权检查员仍不能修改或整改其他检查员录入的记录。

## 覆盖升级

1. 不要卸载旧 APP，不要清除应用数据。
2. 直接安装 `xinyuan-gas-hazard-v2.0.9.apk` 覆盖旧版本。
3. 首次启动会自动将本地数据库从版本 8 升级到版本 9，原记录和照片继续保留。
4. 登录后旧版未上传记录会继续自动上传；未完成云端核对前不要清理本机数据。

## 管理员配置

电脑后台进入“公司与账号”，在账号行点击“编辑权限”：

- 管理员账号可选择“两端”或“仅后台”。
- 检查员可开启“查看本公司全部记录”。
- 权限修改后，该账号现有登录会失效，需要重新登录，以确保新权限立即生效。

## 现场验收

1. 在室外或门头附近开启手机精确定位。
2. 新建记录并拍摄门头照片，核对水印地址、坐标及精度是否随当前位置变化。
3. 提交后在 APP 和电脑后台核对记录及全部照片。
4. 用管理员账号验证 APP 登录；用普通检查员和获授权检查员分别核对数据范围。
