# APP 2.0.10 单端单设备登录说明

## 登录规则

- 同一账号在 APP 与手机 H5 端合计只允许一个有效登录。
- 同一账号在电脑管理后台只允许一个有效登录。
- 同一账号可以同时保留一个手机端登录和一个电脑后台登录。
- 第二台手机或 H5 登录后，旧手机端令牌立即失效。
- 第二个电脑浏览器登录后，旧电脑后台令牌立即失效。
- 旧设备下次访问云端时自动返回登录页，并提示账号已在同一端的其他设备登录。

## 技术约束

- `sessions` 表使用 `(user_id, client_type)` 唯一索引保证每端只有一条会话。
- 新登录通过数据库原子更新替换同端旧令牌，手机端和电脑端令牌互不覆盖。
- 迁移脚本会保留每个账号每个端最新的一条历史会话，并删除同端旧会话。
- 数据库迁移脚本：`database/patches/20260827_single_session_per_client.sql`。
