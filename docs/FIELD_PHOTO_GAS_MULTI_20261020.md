# 拍照校验、整改相册与气源多选筛选

2026-10-20：H5、电脑后台及后端已备份上线；Android v2.3.1（versionCode 26）已生成并验证签名，需在手机安装新版后使用 APP 改动。

## 本次五项改动

1. 整改照片保留拍照入口，并增加手机相册多选。Android 将照片复制到应用自身附件目录；删除附件不删除相册原图。相册上传保留照片原有内容，不人为添加新的拍摄时间水印。服务器支持 JPG、PNG、WebP，单张不超过 10MB。
2. 新增检查中，门头及后续照片在拍照前只校验配送员。后续照片仍先要求已有门头定位，沿用本次地址和坐标。用户名称、电话、类型及检查人填写时才出现在水印中，空白项不生成占位文字；日期、时间及已有定位照常显示。
3. 拍照可以先于用户资料补全。后端允许不完整草稿，草稿不会作为正式记录列出。正式提交仍要求用户名称、电话、类型、地址、检查人、配送员、日期、检查结果、检查片区和门店，以及对应的门头、隐患和气源照片；备注等原有选填项不额外强制。检查结果为隐患未清零时，可选择隐患项目或气源异常；气源异常须有钢瓶二维码或钢瓶照片。
4. 气源排查增加“虚假安检”，同步 Android、H5 和后端目录。
5. 后台隐患项目与气源排查均使用复选框多选。同组任一项目匹配即可，两组之间及其他筛选条件同时生效。清空一组表示该组不限制。列表、同步导出、后台导出任务共用规则，保持旧单项 hazardCode 查询及旧任务兼容，不改变导出列顺序。
